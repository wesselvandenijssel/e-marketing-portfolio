## Releasing an update

To release an update, update the version number in the `metadata.php` on the update server that `buildUpdateChecker()` in `wesselvdijssel-widgets.php` points to. Then add the zipped new version of the plugin to the `files` folder next to it, named `<plugin-slug>-<version-number>.zip`.
